# Portfolio

個人作品集網站,展示前端技能、學經歷、作品,以及刷題與技術筆記等持續學習紀錄。

## 技術棧
- [Nuxt 3](https://nuxt.com/) + TypeScript
- Tailwind CSS
- shadcn-vue
- Nuxt Content(筆記與作品內容管理)

詳細架構規劃請見 [架構.md](./架構.md)。

## 開發

```bash
# 安裝套件
pnpm install

# 啟動開發伺服器
pnpm dev

# 建置
pnpm build

# 本機預覽建置結果
pnpm preview
```

## 頁面
- `/` 首頁
- `/skills` 技能展示
- `/experience` 學經歷展示
- `/works` 作品展示
- `/leetcode` 刷題 dashboard
- `/notes` 筆記集合
